# Potentiometer Resistance Reader (ESP32)

ESP32 project for measuring the resistance of a potentiometer using the board's analog input.

> The sketch has not been uploaded yet — this repository currently holds only the README, license and `.gitignore`.

## Hardware
- ESP32 development board
- Potentiometer wired as a voltage divider to an ADC pin
